# Scoreboard chain images: where each came from

Served from here by the ScoreConnect chain (`_sccImgKeys` in app.js looks up
`device-*`, `cable-*`, `controller-<model id>` then `controller-<brand>`).
Add a file with the right stem and it appears; no code change.

- `device-scorelink.png`, `device-scorelink2.png`: supplied by Ian Moore
  (2026-09-29), downsized to 480px. Originals: ~/Code/Resources/pulse-sc-images/.
- Everything below: photos from the NFHS Network support article "Scoreboard
  Controllers" (Mar 18, 2026), PlayOn's own knowledge base, extracted from Ian's
  PDF export and downsized to 480px JPEG. Approved as stand-ins by Ian
  (2026-09-29) until he supplies his own. Model ids match SC_CONSOLES in main.py.
